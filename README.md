# Task Management System (Avidus Assignment)

A role-based task management application built with React.js, Node.js, Express.js, and MongoDB.

## ✨ Features

- User Authentication
- Role-Based Access Control (Admin/User)
- Task Management (Create, Update, Delete)
- Admin Dashboard
- User Management
- Activity Logs
- Analytics Dashboard
- Protected Routes
- Responsive UI

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router Dom
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT (JSON Web Tokens) for Authentication

## 🚀 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd <project-folder>

```

2. **Backend Setup:**
```bash
cd backend
npm install

```


*Create a `.env` file in the backend folder and add your MongoDB URI and JWT Secret.*
```bash
npm start

```


3. **Frontend Setup:**
```bash
cd frontend
npm install
npm start

```
